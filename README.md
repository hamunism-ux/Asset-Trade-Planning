# 資產買賣紀錄與掛單規劃本 Asset Trade & Ladder Planner · 手機離線版

本地優先的 PWA：介面和資料快取存在手機／電腦上，打開就有畫面；記帳、改狀態、登記成交、改單、加單先存在這台裝置，有網路時自動同步到**自己的 Google 試算表**（透過 Apps Script）。

這個 repo 只有前端檔案（`index.html`、`sw.js`、`manifest.webmanifest`、圖示），**沒有任何資料、網址或金鑰**。同步網址和金鑰只存在使用者自己的裝置上。後端（`Code.gs`、`App.html`、`Seed.gs`）放在試算表的 Apps Script 專案裡。

---

## 一次性設定

### 1. 更新 Apps Script（試算表 → 擴充功能 → Apps Script）
1. 把 `Code.gs`、`App.html` 換成新版（v3.0），按 💾。
2. 函式選單選 **`syncSetup`** → ▶ 執行。執行記錄會顯示一串 64 字元的**同步金鑰**（試算表選單「🧭 掛單工具 → 📱 手機離線版」也看得到）。
3. **部署 → 新增部署作業** → 類型「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**任何人**（手機版不經 Google 登入，靠同步金鑰保護）
   - 部署 → 複製「網頁應用程式」網址（`https://script.google.com/macros/s/…/exec`）

### 2. 開 GitHub Pages
1. 在 GitHub 建一個新的 repo（例如 `asset-ladder-planner`，Public 即可，裡面沒有資料）。
2. 把這個資料夾的全部檔案上傳到 `main` 分支根目錄（包含 `.nojekyll`）。
3. Settings → Pages → Source 選 **Deploy from a branch**，Branch 選 `main` / `/ (root)` → Save。
4. 約 1 分鐘後網址會出現，例如 `https://<你的帳號>.github.io/asset-ladder-planner/`。

### 3. 在手機上使用
1. 用手機瀏覽器打開 Pages 網址，貼上第 1 步的**同步網址**和**同步金鑰** →「連線並下載資料」。
2. 加到主畫面：iPhone Safari「分享 → 加入主畫面」；Android Chrome「⋮ → 安裝應用程式／加到主畫面」。
3. 電腦也可以用同一個網址（每台裝置各輸入一次網址和金鑰）。

## 怎麼運作

| | 存在這台裝置、離線可用 | 需要連線 |
|---|---|---|
| 看資料 | 總覽、資產頁、掛單簿、模擬器、掛單成交狀態、真實交易紀錄（顯示上次同步的資料與現價） | 更新現價（↻） |
| 變更 | 真實交易紀錄（新增／匯入／編輯／確認／刪除）、改狀態、登記成交、編輯／新增／刪除／複製掛單、模擬器安排新掛單、掛單成交狀態、持倉、策略筆記、一般設定、新增帳戶 | 帳戶改名／刪除、資產與現價設定、AI 診斷與 AI 設定 |

- 右上角的同步標記：**✓ 已同步**、**↑N 待同步**（有 N 筆變更還沒送出）、**離線**。點一下立即同步。
- 有網路時會自動送出：變更後約 1 秒、恢復連線時、回到畫面時、每分鐘檢查一次。
- 每筆變更有自己的 ID，網路斷掉重送也不會重複記帳。
- 兩台裝置同時改到同一張單：依送達試算表的順序套用；如果某筆變更已經不適用（例如那張單在另一台已經刪掉），會跳出提示並略過那一筆。
- 試算表永遠是最後依據：每次同步後，這台裝置會換成試算表的最新資料。

## 安全
- 同步金鑰等於這份資料的鑰匙：拿到「網址＋金鑰」的人可以讀寫你的掛單資料。不要分享、不要截圖外流。
- 換金鑰：在 Apps Script 執行 `syncResetKey`，舊金鑰立刻失效，各裝置到「設定 → 同步 → 更改連線設定」重新輸入。
- 「任何人」部署只接受帶正確金鑰的請求，而且只開放 App 用到的功能（不能執行 setup 之類的維護功能）；網頁介面（doGet）也要帶金鑰才會顯示。
- 金鑰錯誤的請求會被延遲回應，避免被暴力猜測（金鑰有 128 位元以上的隨機性）。
- Anthropic API Key 仍然只存在 Apps Script 的使用者屬性，不會傳到手機。
- 「清除這台裝置的資料」會刪掉這台裝置上的快取、網址與金鑰（試算表不受影響）。

## 原本的 Apps Script 網頁介面
還是可以用，但啟用同步金鑰後，舊網址後面要加 `?k=同步金鑰` 才會顯示（因為「任何人」部署和舊部署共用同一份程式）。

## 更新程式
- **前端**：把新的 `index.html`、`sw.js` 上傳覆蓋。手機下次打開會在背景下載新版，再下一次打開就是新版。
- **後端**：替換 `Code.gs` 後，到「部署 → 管理部署作業」把「任何人」那個部署（以及舊的「只有我自己」部署）都編輯成「新版本」。
